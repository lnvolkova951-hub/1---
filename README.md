ГруппаРиска - общее кол-во пациентов, подлежащих вакцинации. ГруппаРиска = Привит + Отказ + Выполн
Привит - кол-во пациентов, вакцинированных ранее.
Отказ - кол-во пациентов, отказавшихся от прививки.
Выполн - кол-во привитых за отчетный период пациентов.
ПроцВыполн - вычисление процентного соотношения привитых пациентов к общему количеству.
ПолнВып - кол-во пациентов, получивших полный курс вакцинации (известно, что их 30% от Выполн).
НеполнВып - получившие неполный курс вакцинации (отказ от след.этапа / аллергич.реакция).
